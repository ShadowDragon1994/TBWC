# 工程质量与 CSV 批量导入实施方案

## 目标

补齐可持续开发所需的 ESLint 质量门槛，并支持小红书、抖音运营数据 CSV 批量导入数据复盘中心。

## 阶段一：工程质量

- 安装官方 `typescript-eslint` flat config 支持。
- 配置 TypeScript、React Hooks、浏览器、Node 和测试环境。
- 忽略构建产物、本地数据和临时目录。
- 修复现有代码中的真实规则问题，确保 `npm run lint` 成功。

## 阶段二：CSV 导入

### 文件契约

- UTF-8 CSV，允许 BOM、引号、逗号和单元格换行。
- 支持中英文表头：
  - 平台 / platform
  - 商品名称 / productName
  - 作品标题 / title
  - 统计日期 / recordedOn
  - 曝光量、播放阅读、点赞、收藏、评论、分享、线索、订单、成交额及英文键
- 平台值归一化为“小红书”或“抖音”。
- 日期统一为 `YYYY-MM-DD`；计数为非负整数；成交额为非负数。

### 导入行为

- 浏览器解析并展示预览与行号级错误。
- 存在错误时禁止提交。
- 服务器再次整体校验，每批最多 1000 条。
- 以“平台 + 标题 + 统计日期”为重复键，已存在记录跳过。
- 返回创建数量、跳过数量和创建后的记录。

## 验证

1. CSV 解析、别名、引号、错误行和 BOM 单元测试。
2. 批量 API 创建、重复跳过、超量和非法输入测试。
3. 前端上传、预览、导入交互测试。
4. 全量 lint、test、build。
5. Edge 文件上传实机回归。
6. 代码审查、提交和推送。
