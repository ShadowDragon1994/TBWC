# 造物台 95% 功能完成度实施计划

## 完成口径

- 平台范围仅为小红书。
- 无外部接口时使用明确标注的模拟数据；所有外部动作经可替换的 RPA/MCP/CLI 适配器。
- 每项功能必须具备可操作页面、业务逻辑、API 或本地执行链、测试和错误提示。
- Photoshop 与小红书真实账号只要求桥接框架，不把模拟结果表述成真实平台结果。
- 登录认证和多租户能力不在个人工具范围内。

## 阶段一：趋势选品与二创

- 小红书趋势和蓝海机会看板，展示原始指标、评分拆解和风险。
- 从机会生成差异化商品定位、标题方向、视觉方向及内容任务。
- 趋势采集通过自动化适配器执行并保留来源标记。

## 阶段二：客服与定制

- 识别送礼/自用、对象、节日、预算、时效、定制诉求和风险。
- 生成客服建议回复，支持人工辅助发送和自动发送。
- 定制确认卡必须完整后才允许自动发送。

## 阶段三：节日、预测与库存

- 年度营销日历、提前 30 天提醒、备货与内容节点。
- 基于模拟历史数据的节日流量预测、误差回测和置信区间。
- 节后长尾清仓规则、组合销售与调价建议。
- 竞品新品、价格变化和异常波动监控。

## 阶段四：PS、发布和治理

- PS/CLI 桥接任务、输入输出清单、动作日志、失败重试。
- 小红书自动上架队列、状态恢复、幂等和持久化审计。
- 合规规则、AI 标识、知识产权白名单、人工复核和紧急停止。

## 阶段五：验收

- 每个模块具备单元、API/组件和关键 Edge 流程验证。
- 输出 PRD 功能矩阵，功能完成度达到 95%。
- 模拟验证与真实账号验证分开统计。

## 风险控制

- 页面自动化受小红书 UI 变化影响：通过适配器和稳定任务协议隔离。
- 模拟数据无法证明商业指标：UI 和报告始终显示数据来源。
- 自动客服存在误发风险：定制、承诺和高风险意图强制转人工。
- 本地进程中断：任务持久化并支持恢复、重试和审计。
