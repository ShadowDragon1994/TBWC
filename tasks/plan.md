# 核心创作闭环实施方案

## 阶段一：持久化任务

- 增加创作任务表、仓储、校验和 API。
- 工作台创建/恢复任务并同步状态。
- 检查点：API、页面测试和构建通过。

## 阶段二：分级合规

- 建立可定位、可处理的本地合规结果模型。
- 增加阻断、确认、忽略与修复交互。
- 导出前执行合规门禁。
- 检查点：规则、UI 与回归测试通过。

## 阶段三：素材包导出

- Canvas 生成 800×800、3:4、9:16 图片。
- ZIP 写入图片、文案和检查报告。
- 保存导出结果与任务完成状态。
- 检查点：Edge 下载回归、Lint、测试和构建全部通过。

## 阶段四：AI 用量与预算

- AI 设置增加输入/输出 Token 单价和月度预算。
- 每次真实生成记录模型、操作、平台、Token、耗时、估算费用和结果。
- 设置页展示本月调用、成功率、Token、费用和预算进度。
- 接口未返回 Token 时明确显示“用量未知”，不推测数据。
- 检查点：真实调用集成测试、统计测试、设置页交互和 Edge 回归通过。

## 风险与处理

- Canvas 跨域图片污染：只使用本机同源上传或打包资源。
- 中文文件名兼容：ZIP 内采用稳定英文目录和 UTF-8 内容。
- 旧数据升级：使用幂等建表，不破坏已有 SQLite 数据。

## 阶段五：预算预警与调用明细

- 预算达到 80% 时在设置页提示，达到 100% 后真实生成和改写必须二次确认。
- 设置页展示逐次调用记录，并支持按小红书、抖音及成功、失败筛选。
- 取消超预算调用时不发送生成请求，避免继续产生费用。
- 检查点：预算规则测试、页面交互、Edge、lint、全量测试和构建全部通过。

## 阶段六：真实 AI 稳定性

- 对 429、502、503、504 临时错误最多自动重试一次。
- 鉴权失败、余额不足和返回格式异常不重试，并给出可操作提示。
- 重试过程只保存一条最终调用记录，不记录商品内容或密钥。
- 检查点：网关集成测试、全量测试、lint 和构建全部通过。
