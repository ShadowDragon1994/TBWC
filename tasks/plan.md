# 核心创作闭环实施方案

## 阶段一：持久化任务

- 增加创作任务表、仓储、校验和 API。
- 工作台创建/恢复任务并同步状态。
- 检查点：API、页面测试和构建通过。

## 阶段二：分级合规

- 建立可定位、可处理的本地合规结果模型。
- 增加阻断、确认、忽略与修复交互。
- 导出前执行合规门禁。
- 检查点：规则、UI 与回归测试通过。

## 阶段三：素材包导出

- Canvas 生成 800×800、3:4、9:16 图片。
- ZIP 写入图片、文案和检查报告。
- 保存导出结果与任务完成状态。
- 检查点：Edge 下载回归、Lint、测试和构建全部通过。

## 风险与处理

- Canvas 跨域图片污染：只使用本机同源上传或打包资源。
- 中文文件名兼容：ZIP 内采用稳定英文目录和 UTF-8 内容。
- 旧数据升级：使用幂等建表，不破坏已有 SQLite 数据。
