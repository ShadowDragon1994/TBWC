# 数据复盘中心实施方案

## 目标

建立面向个人运营的小红书、抖音作品复盘页面。首版支持模拟数据预览和手工录入，不依赖平台开放接口。

## 指标口径

- 流量：曝光量、播放/阅读量。
- 互动：点赞、收藏、评论、分享；互动率 = 四类互动合计 / 播放量。
- 转化：线索、订单、成交额；订单转化率 = 订单 / 播放量。
- 维度：平台、商品、作品、统计日期。

## 交付切片

1. 建立作品表现数据表、校验规则和 CRUD API。
2. 建立模拟数据和纯函数聚合测试。
3. 新增数据复盘导航、指标总览、平台对比和作品排行。
4. 支持从已发布任务选择作品并录入真实数据。
5. 将表现数据纳入完整备份恢复。
6. 完整测试、构建、Edge 回归、审查和 Git 推送。

## 约束

- 计数指标必须为非负整数，成交额必须非负。
- 本地存在真实记录后不再混入模拟数据，避免误导。
- 所有比率在分母为零时显示 0%。
