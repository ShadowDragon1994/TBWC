# 策略转发布任务实施方案

## 目标

让策略页的下周内容清单可以直接生成发布任务，形成“复盘 → 策略 → 排期”的闭环。

## 设计

- 周一、周三、周五、周日分别映射为下一个自然周的 10:00。
- 自动带入商品、平台、选题和策略目标备注。
- 新任务初始状态为“编辑中”，后续仍走现有审核发布流程。
- 页面加载现有发布任务，通过标题和计划日期识别重复项。
- 支持单条创建和一键创建全部未生成任务。
- 创建成功后按钮显示“已创建”并禁用。

## 验证

1. 日期换算、字段映射和重复识别单元测试。
2. 页面交互测试覆盖单条创建。
3. 全量测试、生产构建和 Edge 实机回归。
4. 代码审查后提交推送。
