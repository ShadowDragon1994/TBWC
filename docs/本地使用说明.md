# 造物台本地使用说明

## 启动

双击项目根目录的 `启动造物台.cmd`。

首次启动会安装依赖并进行生产构建，随后在后台启动本地服务并用 Microsoft Edge 打开：

`http://127.0.0.1:3001`

重复双击不会启动第二个服务，只会重新打开页面。

## 停止

双击 `停止造物台.cmd`。

## 查看状态

双击 `查看造物台状态.cmd`，可以查看当前运行状态、访问地址和后台进程 PID。

启动器只接受带有造物台身份标识的健康响应。如果 3001 端口被其他程序占用，它会停止启动并显示明确错误，不会连接到其他应用。

启动、停止和状态脚本通过 `tmp/zaowutai-server.pid` 精确管理造物台后台进程，不会批量关闭其他 Node.js 程序。

## 数据与备份

- 本地数据：`data/`
- 上传图片：`data/uploads/`
- 自动备份：`data/backups/`
- 运行日志：`tmp/zaowutai-server.log`
- 错误日志：`tmp/zaowutai-server-error.log`

应用启动时会检查当天备份，运行期间每小时检查一次。默认只保留最近 30 份自动备份。

自动备份是完整 ZIP，包含商品、图片、创作记录、发布任务和表现数据，可在商品库的备份恢复入口导入。
