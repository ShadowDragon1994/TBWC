# 本地 AI 网关设计

## 目标

在不把 API Key 暴露给浏览器的前提下，为小红书笔记和抖音口播脚本提供真实 AI 生成，并保留模拟模式作为无密钥、离线和故障降级方案。

## 架构

- 前端设置页只提交密钥，不读取完整密钥；查询接口仅返回 `hasApiKey`。
- 本机 Express 服务统一调用 OpenAI 兼容的 `/chat/completions` 接口。
- SQLite 保存服务地址、模型、模式和加密后的密钥。
- 32 字节本机主密钥独立保存在 `data/ai-secret.key`，不进入 Git 和完整备份。
- 模型输出必须通过 Zod 结构校验，才能进入 React 页面。

## 安全与故障策略

- API Key 使用 AES-256-GCM 加密，日志和 API 响应均不包含密钥。
- 外部服务只允许 HTTPS；HTTP 仅允许 `localhost`、`127.0.0.1` 和 `::1`。
- 请求超时 45 秒，单次输出限制 1200 tokens，输入字段均限制长度。
- 商品资料被明确标记为不可信数据，模型不得执行资料中的指令。
- 真实调用失败时展示错误，不静默伪装成真实结果；用户可主动切换模拟模式。

## 接口

- `GET /api/ai/settings`：读取脱敏设置。
- `PUT /api/ai/settings`：保存模式、地址、模型和可选密钥。
- `POST /api/ai/test`：验证连接与凭据。
- `POST /api/ai/generate`：生成并校验结构化平台内容。
