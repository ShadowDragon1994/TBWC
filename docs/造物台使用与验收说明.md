# 造物台使用与验收说明

## 1. 产品说明

造物台是一款运行在个人电脑上的本地 Web 工具，当前优先面向小红书内容运营，用于趋势选品、商品管理、内容创作、客服辅助、节日运营、合规检查、自动化发布、数据复盘和经营监控。

应用只监听 `127.0.0.1`，默认访问地址为：

`http://127.0.0.1:3001`

商品、图片、创作记录、AI 设置、发布任务和运营数据均保存在本机，不需要登录账号，也不会向局域网或公网开放应用端口。

## 2. 运行要求

- Windows 10 或 Windows 11
- Microsoft Edge
- Node.js 和 npm
- 项目文件具有读写权限
- 如使用真实 AI，需要准备兼容 OpenAI Chat Completions 接口的服务地址、模型名称和 API Key

## 3. 启动、状态与停止

### 3.1 启动

双击项目根目录的 `启动造物台.cmd`。

启动器会：

1. 检查是否已经运行，避免重复启动。
2. 首次运行时安装依赖。
3. 执行生产构建。
4. 在后台启动本地 Web 服务。
5. 等待健康检查通过。
6. 使用 Microsoft Edge 打开应用。

重复双击启动脚本只会重新打开页面，不会创建第二个后台服务。

### 3.2 查看状态

双击 `查看造物台状态.cmd`。

状态窗口会显示：

- 当前访问地址
- 是否正在运行
- 后台进程 PID

### 3.3 停止

双击 `停止造物台.cmd`。

停止脚本会根据 PID、项目路径和进程信息精确停止造物台，不会批量关闭其他 Node.js 程序。

## 4. 五个核心模块

### 4.1 商品管理

商品库用于保存创作所需的基础资料。

主要功能：

- 新增、修改和删除商品
- 保存商品名称、类目、价格、材质、受众和使用场景
- 保存商品卖点和禁用词
- 上传 JPG、PNG 或 WebP 商品图片
- 导出和恢复完整 ZIP 备份

建议在创作前完整填写商品信息。AI 和模拟生成只应使用已经提供的商品资料，不应虚构功效、资质、库存或参数。

### 4.2 内容创作

内容工作台用于生成和编辑小红书、抖音内容。

主要功能：

- 在小红书和抖音之间切换
- 使用模拟模式或真实 AI 生成三个候选版本
- 单独改写标题、卖点或正文
- 保存创作记录和版本历史
- 关闭页面后恢复未完成任务
- 检查标题长度、话题标签、口播结构和自定义禁用词
- 执行分级合规检查
- 导出多尺寸 PNG、文案和检查报告 ZIP

合规检查分为：

- 阻断：必须修改，否则不能导出
- 需确认：必须人工确认或修改
- 建议：可以接受建议，也可以明确忽略

本地规则只能提供辅助检查，不能替代平台审核、广告法审查或真实授权证明。

### 4.3 发布任务

发布任务模块用于管理人工发布和自动化发布流程。

主要功能：

- 从创作内容生成发布任务
- 区分小红书和抖音
- 记录待审核、待发布、已发布等状态
- 生成平台发布包和发布前检查项
- 记录 HTTPS 作品链接
- 保存发布时间和任务进度
- 对“可发布”的小红书任务触发自动发布适配器
- 将执行结果和错误持久化到 SQLite 审计记录
- 失败任务可使用新载荷重试，原失败记录不会被覆盖
- 全局紧急停止状态重启后仍然有效

当前交付使用模拟适配器验证完整链路，不包含真实小红书账号登录。后续可将 Mock 适配器替换为 RPA、MCP 或 CLI 供应商实现，而不改变业务页面和任务协议。

### 4.4 数据复盘与策略建议

数据复盘用于导入发布后的表现数据。

主要功能：

- 导入 CSV 数据
- 支持中英文列名和 UTF-8 BOM
- 校验浏览量、互动量、订单量等数值
- 阻止部分错误数据混入有效批次
- 对重复记录执行去重
- 分别统计小红书和抖音表现
- 计算互动率、转化率等指标
- 根据数据生成下一轮内容建议
- 将策略建议转为下周发布任务

演示数据只用于展示界面。正式验收应使用平台实际导出的运营数据。

### 4.5 系统设置

设置模块用于配置 AI 服务和费用控制。

主要功能：

- 切换模拟模式和真实 AI
- 配置 API 地址、模型名称和 API Key
- API Key 加密保存在本机
- 测试模型服务连接
- 配置输入、输出 Token 单价
- 配置每月预算
- 查看调用次数、成功率、Token、耗时和估算费用
- 按平台和结果筛选调用明细
- 预算达到 80% 时预警
- 预算达到 100% 时要求二次确认

对于 429、502、503、504 临时错误，系统最多自动重试一次；鉴权失败、余额不足和返回格式错误不会重试。

## 5. 推荐使用流程

1. 启动造物台。
2. 在商品库新增真实商品并上传图片。
3. 在设置中选择模拟模式或配置真实 AI。
4. 返回工作台，选择商品和目标平台。
5. 生成候选内容。
6. 修改标题、卖点和正文。
7. 处理全部合规问题。
8. 保存创作并导出素材包。
9. 创建发布任务并完成审核。
10. 小红书任务可点击“自动发布到小红书”；也可人工发布后回填链接。
11. 导入真实表现数据。
12. 查看复盘结果和下一轮策略建议。

## 6. 数据目录

| 内容 | 位置 |
|---|---|
| SQLite 数据库 | `data/zaowutai.sqlite` |
| 商品图片 | `data/uploads/` |
| 自动备份 | `data/backups/` |
| AI 本机加密密钥 | `data/ai-secret.key` |
| 运行日志 | `tmp/zaowutai-server.log` |
| 错误日志 | `tmp/zaowutai-server-error.log` |
| PID 文件 | `tmp/zaowutai-server.pid` |

不要单独复制数据库后删除 `ai-secret.key`，否则已经保存的 API Key 将无法解密。跨电脑迁移时，建议使用应用内完整 ZIP 备份；API Key 应在新电脑上重新填写。

## 7. 备份与恢复

应用启动时会检查当天自动备份，运行期间每小时检查一次，默认保留最近 30 份。

完整备份包括：

- 商品资料
- 商品图片
- 创作记录
- 创作任务
- 发布任务
- 表现数据
- AI 用量记录

API Key 不会进入备份文件。

恢复前建议先保留当前 `data` 目录副本。恢复完成后，应检查商品数量、图片、创作记录、发布任务和 AI 用量是否一致。

## 8. 测试状态与真实性边界

当前代码已经通过 132 项自动化测试、lint 和生产构建。2026-07-28 使用本机 Microsoft Edge 150 验证了发布看板自动发布流程：按钮可点击、请求成功、任务状态和作品链接正确回填，浏览器控制台零错误、零警告。

已经使用真实组件验证的部分：

- SQLite 数据库存取和重新打开
- 本地文件上传
- ZIP 备份与恢复
- Express API
- 后台进程、PID 和健康检查
- Edge 页面交互
- Canvas 图片和 ZIP 素材导出

仍需要用户真实数据完成的部分：

- 真实商品和图片的业务验收
- 真实 AI 服务生成质量
- 实际 Token 与供应商账单核对
- 小红书真实账号的 RPA/MCP/CLI 发布结果
- 平台真实 CSV 数据复盘
- 策略建议在实际运营中的有效性

因此，自动化测试通过不等于真实业务效果已经被证明。

## 10. 常见问题

### 页面无法打开

先运行 `查看造物台状态.cmd`。如果未运行，重新执行启动脚本；如果启动失败，查看：

- `tmp/zaowutai-server-error.log`
- `tmp/zaowutai-server.log`

### 3001 端口被占用

关闭占用 3001 端口的程序后重新启动。启动器不会把其他程序误认为造物台。

### 真实 AI 无法连接

依次检查：

1. API 地址是否包含正确版本路径。
2. 模型名称是否与供应商一致。
3. API Key 是否有效。
4. 账户是否有余额。
5. 网络是否允许访问模型服务。

### 导出按钮不可用

检查合规面板。阻断问题必须修改，需确认问题必须明确确认或修改。

### 数据异常或需要迁移

先导出完整 ZIP 备份，不要直接删除 `data` 目录。迁移后重新填写 API Key。

## 11. 当前交付结论

当前版本已经具备个人本机 Web 工具的完整技术闭环，可以进入功能验收。

正式验收完成仍依赖三类真实输入：

1. 一件真实商品及图片。
2. 用户自己的 AI API Key。
3. 一份小红书或抖音真实运营数据。

真实账号自动发布、图片生成模型、自动抠图和原生 PSD 编辑仍依赖外部供应商或桥接程序；当前版本已经提供可替换适配器、Photoshop/CLI 桥接、模拟自动发布、持久化审计、重试和紧急停止框架。
