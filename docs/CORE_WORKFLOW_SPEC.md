# 核心创作闭环规格

## 目标

让个人运营者在 Edge 浏览器中完成“小红书/抖音创作任务 → 分级合规确认 → 多尺寸素材包导出”的本地闭环，并能在失败或关闭页面后继续。

## 技术与命令

- 前端：React 19、TypeScript、Vite
- 后端：Express、SQLite
- 测试：Vitest、Testing Library、Supertest
- 开发：`npm.cmd run dev`
- 测试：`npm.cmd test`
- 检查：`npm.cmd run lint`
- 构建：`npm.cmd run build`

## 本轮范围

### 1. 创作任务

- 创作任务保存商品、平台、文案、当前状态和更新时间。
- 状态按 `draft → editing → checking → confirming → exporting → completed` 前进。
- 导出或检查失败时记录失败状态与原因，任务可重新继续。

### 2. 合规处理

- 检查结果分为红色阻断、黄色确认和蓝色建议。
- 每条结果包含位置、原因、建议和处理状态。
- 红色问题未解决时禁止导出；黄色问题必须确认或修改。
- 本轮只实现确定性的本地规则，不宣称替代平台或法律审核。

### 3. 素材包导出

- 使用浏览器 Canvas 生成小红书 3:4、抖音 9:16 和 800×800 主图。
- ZIP 同时包含 PNG、UTF-8 文案和 JSON 检查报告。
- 导出前执行合规门禁，成功后任务进入已完成状态。

## 测试策略

- 规则和状态流使用单元测试。
- API 使用 Supertest 集成测试。
- 页面交互使用 Testing Library。
- 最终执行完整 lint、test、build，并在 Edge 验证主要按钮。

## 边界

- 始终：本地保存、输入校验、导出前人工确认、API 密钥不进入素材包。
- 本轮不做：图片生成模型、自动抠图、PSD/Photoshop、平台自动发布。
- 不允许：把固定“授权完整”提示当作真实授权检查结果。

## 成功标准

- 用户能创建、恢复并推进一条创作任务。
- 合规问题可定位、处理，阻断项无法绕过导出。
- 一次导出得到至少三张 PNG、文案和检查报告。
- 现有数据和功能兼容，全部测试、Lint 和构建通过。
